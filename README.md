# talking_avatar_journey

Learning the concepts and building blocks behind talking avatars or head driven by audio through hands-on implementation. 

## Map

- **`00_audio/`** - audio features for lip-sync: mel spectrograms, MFCCs, and
  DeepSpeech / wav2vec2 feature extraction.
- **`01_pix2pix/`** - a from-scratch pix2pix (conditional GAN for image-to-image
  translation). See [`01_pix2pix/README.md`](01_pix2pix/README.md).
